---
description: Open and show a file's contents (and offer to edit it)
argument-hint: the file path
---
Open the file named in the arguments and show its contents to the user.
- Use Read; for a large file, show the relevant part and say it's truncated.
- Then ask if they want to change anything — if so, make the edit directly (small, targeted).
For hands-on editing they can also press **Ctrl+Shift+E** → arrow to the file → Enter to edit it in micro (Ctrl+S to save).
