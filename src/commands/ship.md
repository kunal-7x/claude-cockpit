Finish and ship the current work end-to-end:
1. Run the project's tests/build; fix any failures before continuing.
2. Commit in small, logical units with clear messages.
3. Push the branch and open a pull request with a clear summary.
4. Verify the REAL, integrated flow actually works — do not trust per-component green reports.
5. Report what shipped, and anything only I (the user) can verify myself.

Do not skip verification. If something cannot be verified, say so honestly.
