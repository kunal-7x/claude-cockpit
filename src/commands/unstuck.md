description: Panic button — how to escape any stuck/weird state in Claude Code

The user feels stuck or trapped in some mode. Calmly and simply explain how to get back to normal. Cover the most common traps:

- **Stuck in an external editor** ("Save and close editor to continue..."): a Notepad window opened (you pressed Ctrl+G). Find it in the taskbar / press Alt+Tab, then close it (✕). You return to normal instantly. Nothing is lost.
- **Typed text won't send**: press Enter to submit. (Ctrl+G opens the editor — avoid it.)
- **A command seems frozen**: press Esc to cancel the current action.
- **Want to undo / go back**: press Esc twice to rewind to an earlier point in the conversation.
- **Permission prompts in the way / too many**: press Shift+Tab to cycle permission modes.
- **Screen is messy**: type /clear to clear the screen (keeps your project), or /compact to shrink memory.

Ask what they're seeing on screen if it's unclear, then give the exact 1-2 step fix. Keep it short, kind, and non-technical.
